# Course Progress Tracker

## Project Overview
Course Progress Tracker is a Python-based application that helps students manage their courses and track their learning progress.

## Features
- User Login System
- Course Selection
- Topic-wise Learning
- Completed and Pending Topic Tracking
- Progress Percentage Calculation
- Progress Bar Display
- Correct and Wrong Answer Notifications

## Technologies Used
- Python
- Tkinter
- File Handling
- Python GUI

## Modules
1. Login Module
2. Course Management Module
3. Progress Update Module
4. Progress Tracking Module
5. Data Storage Module
6. Display Module

## Objective
To develop a simple application that helps students organize their courses, monitor completed topics, and track their overall learning progress.
